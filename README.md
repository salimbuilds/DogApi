# Random Dog Picture

A small web app that shows a random dog photo each time you click a button. I built it to practice fetching data from an API with JavaScript.

## Features

- Loads a random dog image from the Dog CEO API
- Shows a loading message while the request runs
- Handles errors and displays a message if the request fails
- Disables the button during loading to prevent repeated clicks

## Built with

- HTML
- CSS
- JavaScript (fetch, async/await)
- [Dog CEO API](https://dog.ceo/dog-api/)

## Run it locally

1. Clone the repo:
```
   git clone https://github.com/your-username/dog-api.git
```
2. Open the folder and double-click `index.html` in your browser.

No install or build step is needed.

## What I learned

- Making requests with `fetch` and `async/await`
- Checking `response.ok` and handling errors with `try/catch/finally`
- Updating the page from the JavaScript response
